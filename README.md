# Thrylos Feedback Compass 📊
### Customer Feedback & Review Analytics System

Thrylos Feedback Compass is a web-based customer feedback and review analytics platform developed for **Thrylos**. It helps businesses collect customer feedback, understand customer opinions, and analyze reviews through an interactive dashboard.

The platform provides a simple feedback submission portal for customers and an analytics dashboard for businesses to monitor feedback and identify areas for improvement.

## 🌐 Live Demo

**Website:** https://thrylosfeedbackanalutics.netlify.app/

## 🎯 Problem Statement

Businesses receive customer feedback through different channels, making it difficult to organize, understand, and analyze customer opinions effectively.

Without a centralized system, identifying customer satisfaction levels, recurring complaints, and improvement opportunities can become time-consuming.

Thrylos Feedback Compass aims to simplify this process by providing a centralized platform for collecting and analyzing customer feedback.

## ✨ Key Features

- **Customer Feedback Form:** Allows customers to submit their reviews and experiences.
- **Centralized Feedback Collection:** Stores customer feedback in one place.
- **Sentiment Analysis:** Helps identify positive, negative, and neutral customer opinions.
- **Analytics Dashboard:** Displays feedback insights through visual charts and statistics.
- **Feedback Monitoring:** Helps businesses review customer responses and identify common concerns.
- **Interactive Interface:** Provides a simple and user-friendly experience.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/rishikasingh78/thrylosfeedbackanalytics.git
```

**2. Navigate to the project folder**

```bash
cd thrylosfeedbackanalytics
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the project root and add your Supabase credentials using the variable names expected by the application.

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Never upload your actual secret keys or `.env` file to GitHub.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

**6. Build for production**

```bash
npm run build
```
